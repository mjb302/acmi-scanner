# ACMI Scanner site

Public landing page for the ACMI Scanner app (GitHub Pages): https://mjb302.github.io/acmi-scanner/

- `index.html` landing page with animated walkthrough and download links
- `privacy.html` privacy notice (required for app-store listings)
- `assets/` screenshots, icon, EnRICH logo, sample medication list

The Android APK is attached to GitHub Releases, not committed. App source lives in the private
project folders; the shared data files (ACMI/STOPP map, deprescribing advice) are in
`~/Documents/ACMI Shared/`.
